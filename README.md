# Jintong Wang — Portfolio

Personal portfolio for [Jintong Wang](https://github.com/Gintong10): products, games, and tools.

**Live:** [gintong.dev](https://gintong.dev) · [GitHub Pages](https://gintong10.github.io/portfolio/)

## Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Pushes to `main` deploy via GitHub Actions → GitHub Pages.
Custom domain: `gintong.dev` (see `public/CNAME`).
